# Miowser 0.1.91 (code 92)

- Browser and Media/Player settings now have a permanent inline search field below the title bar. Tapping it opens the keyboard on the same page.
- Results appear within the settings page as you type. Clearing the query restores the existing settings and scroll position; selecting a match still opens and highlights its control.
- Centered the no-results icon, heading, and explanation across the available width.
- Back clears an active query before leaving settings. The search icon and separate Search screen were removed.

Device testing is left to you.
