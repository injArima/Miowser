# Miowser 0.1.84 (code 85)

- Added 14 color themes from your reference palettes: Sea, Amber, Black Gold,
  Summer Ocean, Halloween, Retro, Sunset, Space Man, Wood, Cotton Candy, Grass,
  Ice Cream, Night, and Umbrella.
- Choose a palette in **Settings → Interface → Color theme** or the browser's
  **Theme** menu. Swatch previews use the original image colors, and selections
  apply immediately across the app.
- Color theme and appearance are independent: use any palette with System,
  Light, Dark, or AMOLED appearance. Wallpaper colors and the existing Miowser
  palette remain available.
- Each palette supplies complete Material 3 color roles, including tonal
  surfaces, controls, and snackbars. Text and control colors are adjusted for
  readable contrast; semantic error colors and fixed player control colors are
  preserved.
- Appearance and palette choices persist across restarts and are now included
  in backups. Older backups remain supported and retain the current appearance
  when they contain no appearance settings.

On-device testing is left to you. Check your preferred palettes in light/dark
appearance, the scrollable theme picker, app restarts, and backup/restore.
