# Miowser 0.1.89 (code 90)

- Introduced Material 3 Expressive segmented styling for settings and similar
  navigation/management lists: larger outer corners, smaller inner corners,
  narrow row gaps, and fully rounded single-item groups.
- Applied the shared style across Browser/Media settings and their subpages,
  the hub's settings links, Library option sheets, browser page actions,
  bookmarks, site permissions, browsing-data choices, folder management,
  blocked-element rules, crash reports, and theme appearance choices.
- Added relevant settings-navigation icons and descriptions for the Interface,
  Video, Subtitles, and Advanced categories. Rows grow with wrapped labels;
  shared geometry is centralized in design tokens.
- Kept Neutral backgrounds/text, Secondary selections, Tertiary complementary
  icons, and semantic delete/error colors consistent with the theme contract.
